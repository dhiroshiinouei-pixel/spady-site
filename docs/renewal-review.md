## 2. 既存サイトからの変更

- 地域プロジェクト中心のトップから、「店舗・小規模事業者の集客と運営を支える事業」の構成へ変更。
- 自社SaaSの企画・開発準備と、現在依頼できる受託支援を区別。Google・LINEの公式提供や認定とは誤認されない表現に。

- 余白、文字の大小、自然な日本語のまとまり、落ち着いた配色を統一。大量のスクロール演出を避け、開幕・言語切替・小さな回転とボタンの反応に整理。
- ThreadsとLINEはアイコン付き。お問い合わせCTAはラベルを中央に配置。
- 小樽暮らしカレンダーは既存の公式OGP素材を継続使用。新OGPは1200×630、約80KBのオリジナル図形と文字。

## 8. SaaSの追加方法

`src/data/services.ts` の `services` 配列に追加します。`id`, `name`, `summary`, `audience`, `icon/image`, `status`, `features`, `detailUrl`, `pricing`, `externalUrl`, `contactTopic` を一か所で管理します。

- IDは一意の英小文字・ハイフンを基本にし、`detailUrl` を `/services/ID/` と一致させます。
- 長い日本語名は `nameParts` に意味のまとまりを設定すると、狭い画面での改行を調整できます。
- ステータスは `planning / developing / preparing / available / ended`。
- 問題・機能・利用の流れ・FAQ・商標/非公式の注記も同じデータに記入。
- `externalUrl` は将来の独立サイト・サブドメインのHTTPS URLに利用できます。追加するだけで決済が開始されることはありません。
- 画像を追加する場合は `image` と `imageAlt` にパスと代替説明を設定。
- `npm run build` でサービス一覧・詳細ページ・サイトマップが生成されます。トップは先頭2件を紹介し、一覧へのリンクで残りを案内します。
- 企画中から提供中へ変える場合は、ステータスだけでなく、概要・機能・料金注記・FAQを実際の提供内容に合わせ、法的表示と契約導線も更新してください。
